# 亳伯奇难题（更理想的宫帐政体）

Crusader Kings III 宫帐政体 Mod 项目。仓库包含完整当前 Mod 源码及开发说明，可用于继续开发和问题排查。

## 当前快照

2026-10-31：R72 完整源码 + R76 中英文本地化补丁。描述符支持 `1.20.*`，保留现有版本标签 `FIX4-R52-personal-maa-test-20261015`，不据此宣称全版本兼容。历史实测涉及 1.20.1 / 1.20.1.1；本次上传没有新增游戏测试。

## 功能与目录

- 宫帐独立庄园类型与原生世族住所接线。
- 账户/住所生命周期、牧群资源、兵士与军事界面、建筑迁移和合约相关脚本。
- `pgh_accounts/`：完整可安装 Mod；`docs/`：机制、开发、安装、验收和已知问题；`tools/`：源码哈希核验。
